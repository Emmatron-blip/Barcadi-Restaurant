# Barcardi Restaurant & Cafe 🍽️

A modern, responsive website for Barcardi Restaurant & Cafe, designed to showcase the restaurant's menu, highlight its food and beverages, and provide visitors with an attractive browsing experience.

## ✨ Features

- **Responsive Design:** Adapts to different screen sizes, including mobile phones, tablets, and desktops.
- **Interactive Menu:** Displays food and beverage items in organized cards.
- **Food and Drink Categories:** Separates menu items using category attributes.
- **Food Photography:** Uses online images to present menu items visually.
- **Lazy Loading:** Improves initial page loading by deferring off-screen images.
- **Menu Pricing:** Displays prices in Nigerian naira (₦).
- **Clean Interface:** Provides a modern and user-friendly browsing experience.

## 🥤 Menu Highlights

The website features menu cards for selected food and beverage items, including:

- Grilled Chicken
- Classic Burger
- Jollof Rice
- Refreshing Cooler

*Menu items and prices are examples and can be customized to reflect the restaurant's actual offerings.*
